Privacy Policy

Last updated: May 2026 · gitscan Chrome Extension & Web App

gitscan ("we", "our", or "the extension") is an open-source security scanner for Git repositories. This policy explains what data is collected, how it is used, and your rights regarding that data.

1. Data We Collect

The extension collects only the minimum data required to perform a security scan:

  • Repository URL — the public Git repository URL you submit for scanning. This is sent to our backend API to initiate the scan.
  • Scan results — security findings returned by the backend are displayed locally in the extension popup and on our web app.

We do not collect your name, email address, IP address, browsing history, authentication tokens, or any other personal information.

2. How Data Is Used

  • Repository URLs are cloned temporarily on our server for static analysis, then deleted immediately after scanning.
  • Scan results are stored to generate a shareable report link (e.g. /report/UUID).
  • No data is sold, rented, or shared with third-party advertisers.

3. Remote Connections

The extension communicates exclusively with the gitscan backend at gitscan-production.up.railway.app. This connection is required to perform repository scanning and retrieve results as JSON data. No scripts or executable code are ever received from the remote server. No other remote hosts are contacted.

4. Third-Party AI Services

Scan analysis may use AI services (MiniMax, Anthropic Claude) to generate security summaries. Only sanitized code content from the scanned repository is sent — no user identity data. These services operate under their own privacy policies.

5. Data Retention

Scan results are stored for 30 days and then automatically deleted. Cloned repository files are deleted immediately after scanning completes.

6. Your Rights

Since we do not collect personal data, there is no personal profile to access or delete. You may request deletion of a specific scan report by contacting us via the links below.

7. Contact

Questions or requests: open an issue at github.com/gitlawbscanner/gitscan or message @gitlawbscan on X .
